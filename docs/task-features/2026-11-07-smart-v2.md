# Roadmap 8: Smart mode v2 (MMPX, texture-model routing, dither softening)
## Summary
app/core/mmpx.js: MMPX 2x per pass (McGuire & Gagiu 2021, MIT reference), edge-mode aware, then nearest for 3x/6x/Fit. smart.js routes: mmpx (binary-alpha ≤16 colours ≤64 px, or ≤8 colours ≤64 px), pixel (≤16 px), ai (≥32 px, ≥96 colours; GameAI with the models), aisprite (models: binary alpha, 16–64 px → Pixel model), hd. Dither detector (left=right and up=down, both ≠ pixel, within 56/channel) → score; ≥0.12 marks the texture, and HD/AI routes soften dots halfway to their side average (also before the AI). Method row gains MMPX; estimate and preview show the new routes.
## Decisions
- 1x dedither / DEDXT models moved to roadmap 11 (Real-ESRGAN can't run 1x); a non-AI dot softener stands in.
- HDCube never auto-picked (card: not for icons/text; GameAI covers the same textures).
- Detector ignores 1 px lines and real edges by design; brick with mortar and noise score 0.
