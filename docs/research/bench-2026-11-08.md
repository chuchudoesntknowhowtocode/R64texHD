# AI speed on the user's laptop (roadmap 13) — 2026-11-08
tools/bench.ps1, v0.9.2.0, 20 SF2 Turbo captures (512×256, 2.1 Mpx in), 4× out. Raw CSV: bench/bench-20261108-0956.csv (gitignored).

| Engine / model | RTX 4060 Laptop | Intel UHD | CPU |
|---|---|---|---|
| ncnn Real-ESRGAN x4plus | **1.06 s**/texture | 6.35 s | – |
| ONNX DirectML RGT-S dither | 5.70 s | 25.6 s | 32.0 s (3 textures) |
| ONNX DirectML TextureDAT2 | 4.94 s | 25.7 s | – |

- Card order: Real-ESRGAN gpu0 = RTX, gpu1 = Intel (from its log). DirectML device 0 = the fast one (5× faster than device 1, so the RTX); names aren't logged by the runner.
- Both engines' "auto" pick the RTX here: no change needed.
- ONNX models are ~5× slower than x4plus on the same card (heavier models, and DirectML runs some nodes on the CPU: onnxruntime warns "Some nodes were not assigned to the preferred execution providers").
- Intel DirectML is only ~20% faster than the CPU; a CPU lane with these models (~32 s per 512×256) is not worth it. N64 textures are mostly ≤ 128 px (8–30× fewer pixels), so real runs are far shorter.
- Not measured: AMD, ncnn vs DML with the same model (no ncnn build of TextureDAT2/RGT-S), atlas batching, TensorRT/WinML.
